# 1 ในร้อยล้าน: ดาร์กแฟนตาซีต่างโลก (Tarnished Isekai Souls)

เกมจำลองชีวิตผสมผสานระบบ Turn-Based RPG Roguelike สไตล์ Dark Fantasy + Isekai Lore (Dark Souls / Berserk / Re:Zero / KonoSuba / Overlord / Elden Ring)
ออกแบบเนื้อเรื่องร้อยเรียงข้ามช่วงวัย ความยาวการเล่นรอบละ **8 – 15 นาที**

---

## 🌟 ฟีเจอร์ใหม่ที่อัปเกรดล่าสุด:

### 1. 🎲 ระบบสุ่มพรต่างโลก (Blessings Gacha) พร้อมกำหนดเรต:
* 🌟 **SSR (เรตรวม 5% - พรโกงระดับตำนานแต่มีข้อแลกเปลี่ยน):**
  - **หวนคืนจากความตาย (Return by Death - Re:Zero):** เมื่อพลังชีวิตเหลือ 0 จะฟื้นคืนชีพเต็มหลอดทันที 1 ครั้งในชีวิต!
  - **จิตวิญญาณเกราะคลั่ง (Berserk Armor):** พลังโจมตีมหาศาล STR +20, ATK +30, Max HP +50 แต่เสีย SAN -15
  - **มรดกตกทอดจากมหาสุสานนาซาริก (Overlord Ring):** พกเหรียญทองติดตัว +250G และ INT +15
* 🔮 **SR (เรตรวม 15% - พรระดับดี ช่วยให้เอาชีวิตรอดเก่ง):**
  - **ประกายไฟแห่งลัทธิคลั่ง (Frenzy Flame - Elden Ring):** INT +10, STR +8 แต่เสีย SAN -10
  - **สัญชาตญาณควักไส้นักล่า (Bloodborne Visceral):** ติดคริติคอลบ่อย และดูดเลือดฟื้น HP
  - **เส้นสายมานามหาศาล (Laplace Factor - เกิดใหม่ทั้งที):** INT +18 แต่ร่างกายบอบบาง
* ⚪ **Common (เรตรวม 50% - พรขยะ/กาวๆ แบบ KonoSuba):**
  - **ปาร์ตี้ทริกเสกน้ำพุ่ง (Aqua Party Trick):** เสกน้ำออกจากพัด คลายเครียด SAN +5, Gold +5
  - **กระเป๋าเก็บขนมปังขึ้นราไม่อั้น:** มีขนมปังขึ้นราโผล่มาทุกปี พอกินกันตาย
  - **วิชาถอดผ้าวิ่งสับตีนแตก:** ไม่ใส่เสื้อผ้าจะวิ่งหนีศัตรูไวขึ้น 30%
* 🌫️ **ไม่มีพร (เรต 30% - มนุษย์ธรรมดาไร้พลัง):**
  - เทพธิดาละเลย ไม่มอบพรใดๆ ให้ ต้องดิ้นรนด้วยตัวเอง 100%

### 2. 💀 ระบบคำสาปกำเนิด (Innate Curses):
- **กลิ่นอายแม่มด (Witch Miasma):** มอนสเตอร์ดุร้าย วิ่งเข้าใส่บ่อยขึ้น 50%
- **หนี้สินวิญญาณแห่งราชอาณาจักร:** เริ่มต้นชีวิตด้วยเงินติดลบ -40G
- **กระดูกเปราะบางร้าวราน:** ได้รับความเสียหายจากการต่อสู้แรงขึ้น 1.25 เท่า
- **ฝันร้ายแห่งสุริยุปราคา:** ฝันเห็นปีศาจฉีกเนื้อตัวเองทุกๆ 3 ปี เสีย SAN -10
- **ดวงดึงดูดคนเหลี่ยมจัด:** โดนคนหลอกลวงบ่อยเป็นพิเศษ

### 3. 📜 มหากาพย์เชื่อมโยงเนื้อเรื่องตามช่วงวัย (Interconnected Storyline):
* **วัยเด็ก (0 - 10 ปี):**
  - *ปรากฏการณ์มานามรณะ (Mushoku Tensei):* พายุแสงวาร์ปพัดพาครอบครัวกระจัดกระจาย
  - *พบเด็กชายผมขาวดวงตาสีฟ้า (Berserk Prologue):* ช่วยเด็กชายผมขาวไว้ เขาจะมอบเศษไข่หินสีแดง (Behelit Shard)
  - *เทพธิดาผมฟ้าหนีเจ้าหนี้ (KonoSuba):* แอบในถังขยะบ้านเรา
* **วัยรุ่น (11 - 25 ปี):**
  - *คำเชิญชวนจากกองพันเหยี่ยว (Band of the Hawk):* เพื่อนผมขาวในวัยเด็กชวนเข้าร่วมกองทัพ
  - *วาฬขาวแห่งหมอกมรณะ (Re:Zero):* หมอกลบตัวตนที่ต้องกลั้นหายใจเอาชีวิตรอด
  - *สายลับโครงกระดูกนาซาริก (Overlord):* มอบแผนที่แลกเงินทอง หรือสู้กับเวท Grasp Heart
* **วัยผู้ใหญ่ (26 - 45 ปี):**
  - *คืนสุริยุปราคาเลือดและการสังเวยพวกพ้อง (The Eclipse Climax):* เพื่อนสนิทใช้เบเฮริทบูชายัญเรา!
  - *แพตช์จอมถีบ (Patches):* ชี้หน้าผาบอกมีสมบัติ แล้วถีบตูดเราตกเหว
  - *ตู้กดน้ำกระป๋องฟรีดักควาย:* ตู้ล้มทับดับอนาถ
* **วัยชรา (46+ ปี):**
  - *ยุคแห่งเปลวไฟมอดดับ (Age of Dark):* สละร่างต่ออายุไฟ หรือเฝ้ามองโลกมืดมิด
  - *การมาถึงของ Truck-kun สิบล้อแห่งหายนะ:* รถบรรทุกพุ่งชนข้ามมิติส่งวิญญาณไปเกิดใหม่
